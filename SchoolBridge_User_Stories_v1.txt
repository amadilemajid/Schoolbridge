SchoolBridge — Development User Stories
This document contains all user stories for the SchoolBridge platform, organised by epic. Each story follows the standard format: As a [role], I want to [goal], so that [benefit]. Every story includes acceptance criteria, priority (MoSCoW), and story point estimate for sprint planning.

Stories marked MUST HAVE form the MVP backlog. SHOULD HAVE stories target v1.1. NICE TO HAVE stories are planned for v2.0 and beyond.

EPIC-01Authentication & User Management
